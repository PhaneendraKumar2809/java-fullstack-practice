# Java and Web Practice

Practice programs from learning Java fundamentals and front-end basics (HTML and CSS). The repository is organised by topic.

## Contents

### Java (`java/`)
| File | What it covers |
| --- | --- |
| `BankApp.java` | Simple bank account application |
| `CLI.java` | Command-line program |
| `CaluclatorMethods.java` | Calculator using methods |
| `EvenOdd.java` | Even/odd check |
| `Expense.java` | Expense tracking with classes |
| `Palindrome.java` | Palindrome check |
| `ReverseString.java` | String reversal |
| `StudentConstruct.java` | Constructors with a Student class |
| `TableGenerator.java` | Multiplication table generator |
| `hello.java` | Hello world |
| `myapplet.java` | Applet example |

### HTML and CSS (`html-css/`)
Practice pages covering forms, tables, basic layout and a personal portfolio page (`portfolio1.html`, `Portfolio1.css`).

## Skills practised
- Java: classes and objects, constructors, methods, strings, basic input/output
- HTML: forms, tables, page structure
- CSS: basic styling and layout

## How to run a Java file
```bash
javac BankApp.java
java BankApp
```
Replace `BankApp` with the file you want to run.
